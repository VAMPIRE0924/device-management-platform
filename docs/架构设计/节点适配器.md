# 节点适配器

## 能力映射

| 平台动作 | 节点能力 | 平台约束 |
|---|---|---|
| 健康检查 | 客户端列表或状态查询 | HTTPS 且校验 TLS 主机名 |
| 创建项目 | 查询 Client 与 SOCKS | 校验 Client ID 与 SOCKS ID 相同，不创建节点资源 |
| 查询托管通道 | 按 SOCKS 类型查询 | Client 与通道一一映射 |
| 通道启停 | 按 Client ID 操作 | 等待节点真实状态，不提前显示成功 |
| Web/WebSSH/发现 | 获取 SOCKS 路由 | 路由和凭据只存在服务端内存 |
| 创建端口转发 | 创建原生转发任务 | 仅非 Web Endpoint，节点全局检查端口冲突 |
| 启停/删除转发 | 对应任务动作 | 数据库和节点状态均可追踪 |

## 鉴权

节点账号密码由管理员在节点配置中填写，后端使用 AES-256-GCM 加密存入 SQLite，API 只返回“已配置”。内部适配器解密后使用如下会话结构：

```json
{"type":"session","username":"管理账号","password":"只在服务端内存中使用"}
```

上述示例只说明内部结构，真实值不得写入文档、日志、URL 或 API 响应。备份数据库时必须同时备份数据目录中的凭据主密钥。

## 一致性规则

- 外部接口响应差异在适配器层转换，业务层不解析外部页面或原始字段。
- 启停动作在外部接口接受后继续轮询实际状态；超时未达到目标即返回失败。
- 新建或复用端口转发时确认监听实际运行。
- 节点不可达或状态不一致时返回可诊断错误，不伪装成功。
