# 数据模型

当前 SQLite schema：v21。

## 主要实体

- `nodes`：节点管理 API、TLS 校验主机名、端口池、启用状态和加密凭据引用。
- `node_credentials`：以节点 ID 为关联数据，只保存 AES-256-GCM 随机 nonce 和密文；主密钥不进入数据库。
- `projects`：客户边界及其绑定的节点、既有 Client。
- `project_networks`：项目允许扫描的 IPv4 CIDR，不是已登记设备的访问白名单。
- `project_scan_ports`：项目自动发现的具名协议与端口列表。
- `devices`：项目内唯一主机地址、名称、类型、厂商、来源和状态。
- `endpoints`：设备的一对多具名服务；唯一键为设备、协议和目标端口。
- `port_forwards`：非 Web Endpoint 的节点入口、状态和到期时间。
- `access_sessions`：Web/WebSSH 短期令牌哈希、来源、状态和到期时间。
- `users`、`project_memberships`、`access_policies`、`policy_users`、`policy_projects`：角色、项目范围和临时能力授权。
- `user_mfa`、`mfa_recovery_codes`、`mfa_challenges`：邮箱、TOTP、恢复码和短期挑战。
- `discovery_jobs`、`discovery_results`：扫描任务、结果和协议证据。
- `audit_logs`：操作者、动作、资源、请求 ID、来源 IP 和结果。

## 关键约束

- 平台对象使用不可预测字符串 ID；节点数字 ID 必须与节点 ID 和资源类型组合定位。
- Endpoint 协议覆盖 HTTP、HTTPS、SSH、RTSP、RDP、MySQL、PostgreSQL 和 TCP。
- HTTPS Endpoint 可独立保存 TLS 主机名；客户内网 HTTPS 统一允许自签证书。
- SSH Endpoint 可保存登录方式、用户名、加密密码引用或服务器私钥文件路径，以及可选固定主机指纹；API 只返回是否已配置。
- 设备批量导入和设备/Endpoint 替换必须在一个事务中完成。
- Endpoint 只有协议或目标端口变化时清除验证状态；名称或安全设置变化保留协议证据。
- schema v10-v12 增加索引、MFA 和凭据密文库；v13-v17 清理节点旧连接字段并增加项目扫描端口；v18-v20 增加 SSH 登录配置并将无法识别的发现设备名归一为 IP；v21 移除未生效的未知主机密钥开关字段。

## 删除与引用

- 项目存在端口转发、活动访问会话或运行中扫描时拒绝删除。
- 设备被活动会话或转发引用时拒绝删除。Endpoint 只能随设备整体原子替换。
- 项目只引用既有 Client；创建和删除项目都不会修改节点 Client 或 SOCKS 代理。
