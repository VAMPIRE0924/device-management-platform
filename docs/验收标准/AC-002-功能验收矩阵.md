# AC-002 功能验收矩阵

| ID | 能力 | 验收标准 | 当前状态 |
|---|---|---|---|
| AUTH-001 | 初始化与登录 | 初始化令牌、登录、退出、CSRF、角色边界和会话过期正确 | 已验证 |
| AUTH-002 | 首次登录 | 改密、邮箱验证、TOTP/邮箱 MFA、恢复码完整，未完成前拒绝业务 API | 已验证 |
| AUTH-003 | MFA 恢复 | 管理员不能自助绕过；其他用户重置、离线重置和会话撤销正确 | 已验证 |
| NODE-001 | 节点管理 | 可新增、编辑、搜索、启用/维护、健康检测；TLS 与加密账号密码不泄露 | 已验证 |
| NODE-002 | 托管通道 | 展示节点全部通道，支持搜索、手动启停、访问前自动启动，并如实显示运行中/非活跃；空闲停用由节点负责 | 已验证 |
| NODE-003 | 节点 Client | 点击节点卡片可查看真实 Client 只读列表与默认隐藏的单 Client 认证信息；新增时 Basic 用户名必填，密码/唯一密钥留空则按节点默认格式安全生成；不存在公开修改或删除接口 | 已验证 |
| PROJ-001 | 项目 | 项目绑定节点与 Client，CIDR 只用于设备发现，刷新保留项目页面 | 已验证 |
| PROJ-002 | 删除 | 项目与设备依赖保护、二次确认正确；Endpoint 随设备原子保存 | 已验证 |
| DEV-001 | 多服务设备 | 同设备多个具名 Web/SSH/原生 Endpoint 通过设备配置一次性原子新增、编辑、删除且不丢字段 | 已验证 |
| DEV-002 | 手工与 CSV | 手工添加保留，CSV 同主机多行合并；任一错误时整批不写入 | 已验证 |
| DISC-001 | 自动发现 | 只扫描授权 CIDR/端口，支持非标准端口和服务命名，要求协议证据 | 已验证 |
| DISC-002 | 单设备检测 | 只检测已登记 Endpoint，真实更新设备和服务状态 | 已验证 |
| WEB-001 | Web 会话 | 五分钟短期会话、来源校验、撤销和过期正确 | 已验证 |
| WEB-002 | Web 代理 | 不创建转发；请求头、Cookie、重定向、根路径和 HTTPS 信任正确 | 已验证；生产 wildcard 待验收 |
| SSH-001 | WebSSH | 非 22 端口、保存密码/服务器私钥路径、本次临时密码、可选固定指纹、键盘/粘贴、错误提示和实时撤销正确 | 已验证 |
| FWD-001 | 原生转发 | 仅非 Web Endpoint；端口池、冲突、启停、到期和删除正确 | 已验证 |
| USER-001 | 用户与策略 | 用户唯一性、项目成员、临时策略能力和有效期正确 | 已验证 |
| PORTAL-001 | 访问门户 | 只展示授权项目；搜索覆盖设备、IP、项目、服务名、协议和端口 | 已验证 |
| MON-001 | 运行监控 | 只显示真实节点、通道、流量、会话和转发数据，不展示模拟曲线 | 已验证 |
| AUDIT-001 | 审计 | 配置、访问、扫描、转发、恢复相关动作可追踪且不记录秘密 | 已验证 |
| DATA-001 | 备份恢复 | 一致性备份、完整性检查、恢复前快照、schema 检查和 Secret 边界正确 | 已验证 |
| UI-001 | 前端冻结 | 主菜单、项目三标签、列表分页、固定顶部/侧边栏、按钮分工、字号和提示符合 PD-002 | 已验证 |

“已验证”只表示当前代码基线通过对应证据。修改相关模块后必须重新执行该行所需验收，不能沿用历史结论。
