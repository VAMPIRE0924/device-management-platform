# AC-003 真实环境验收

## 授权规则

真实节点默认只读。启停通道、扫描、建立 SSH、创建转发或修改节点对象前，必须获得用户对测试 Client、CIDR、设备和动作的明确授权。验收结束必须停止临时通道、删除临时转发、吊销访问会话并记录最终状态。

禁止：

- 扫描未明确授权的 CIDR；
- 操作现有客户 Client 或任务；
- 把密码、令牌、私钥、页面正文或公共连接密钥写入文档和日志；
- 为 Web 服务创建端口转发；
- 用关闭 TLS 校验的临时方式作为生产结论。

## 当前受控基线

已确认测试 Client 可达 `10.10.0.0/16` 和 `192.168.1.0/24`。该授权只说明历史受控验收范围，不自动授权以后扫描整个网段。

当前协议证据包括：

| 目标 | 已确认服务 |
|---|---|
| `10.10.0.1` | SSH 22，HTTP 80/3000/3001，HTTPS 443 |
| `10.10.10.1` | HTTP 80，HTTPS 443 |
| `10.10.10.2` | HTTP 80/3000，HTTPS 443；3001 为人工未验证服务 |
| `10.10.10.254` | HTTP 80 |
| `192.168.1.1` | HTTP 80，HTTP/JSON 8080 |
| `192.168.1.9` | HTTP 80，HTTPS 443 |
| `10.10.0.255` | 专用 SSH 22 测试设备 |

不得把相同页面标题或指纹作为跨地址自动合并设备的依据。SOCKS CONNECT 成功也不能作为开放端口证据，必须取得 HTTP、TLS、SSH Banner 或对应协议响应。

## 已完成验收

- 受信 HTTPS 管理连接、20 个 Client 和托管通道查询。
- 测试 Client 通道受控启停并恢复停止。
- 授权 `/32` 目标和指定端口的发现，取得真实协议证据。
- 同设备多 Web 和非标准端口访问。
- 两个 AdGuard Home 登录页、首屏 JS/CSS/图片、会话内 API 401 透传。
- LuCI 会话内跳转、主题资源和授权页。
- 专用 SSH 设备的外部凭据登录、固定主机指纹、真实终端和撤销。
- 临时原生转发的创建、SSH Banner、停止、重启、删除和端口关闭。
- 全部 Web 验收过程中没有创建 Web 端口转发。
