## 状态定义

- 未实现：代码中不存在或仍使用假数据。
- 已实现：代码和自动化测试存在，但未完成要求的真实环境验证。
- 已验证：对应自动化或真实验收有可重复证据。
- 受阻：依赖外部凭据、DNS、证书、SMTP、网络或明确授权；必须写清解除条件。
- 不适用：只在验收标准明确说明原因时使用。

## 完成定义

一个任务只有同时满足以下条件才能标记完成：

1. 行为符合产品决策和权限边界。
2. 成功、失败、空态、加载、取消、过期和刷新场景按影响范围覆盖。
3. 自动化测试通过，不依赖未声明假数据。
4. 涉及真实协议时取得真实响应证据；涉及外部写操作时恢复原状态。
5. 不泄露密码、令牌、私钥、SOCKS 凭据或敏感页面正文。
6. 相关文档和开发日志已更新。
7. 未完成的外部门禁明确保留，不能用“应该可用”冒充已验收。
