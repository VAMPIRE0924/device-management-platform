# 2026-08 开发日志

## 2026-08-15 正式版需求收敛与全面回归

- 当前文档、前端交互和后端合同统一以本轮正式版需求为准，不再使用旧原型界面推断产品行为。
- 项目 CIDR 明确改为“设备发现网段”：只限制扫描，不拒绝手工登记设备的访问和转发。
- 设备配置统一原子保存 Endpoint，删除前后端已无调用者的单 Endpoint 新增、修改和删除接口。
- HTTPS 配置下放到每个 HTTPS 服务，内网设备自签证书默认允许且不显示多余开关。
- SSH 管理配置收敛为密码登录或服务器私钥路径；临时 WebSSH 只接收本次用户名/密码，移除未生效的未知主机密钥开关与临时私钥协议。
- schema 升至 v21；节点与 SSH 密码密文可随 SQLite 备份恢复，解密主密钥仍必须成组备份。
- 列表页统一分页，顶部品牌栏与左侧导航固定，只让右侧主内容滚动；同时提升全局小字号可读性。
- 前端契约测试已从依赖变量名和 JSX 排版的脆弱断言，改为验证正式版产品合同。

## 2026-08-15 节点凭据加密持久化

- 节点配置界面支持直接填写管理账号和密码；保存后不回显，再次打开为空，可只输入新密码轮换。
- schema v12 新增 `node_credentials`，使用 AES-256-GCM 加密存储，数据库和 API 不含节点密码明文。
- 数据目录自动生成 0600 权限的 `i5cloud.secrets.key`；SQLite 快照与该主密钥成组恢复即可保留全部节点配置。
- 节点表单只保留认证账号和密码，移除容易引起误解的外部密钥引用入口，并禁止用户伪造内部 `db://` 引用。
- 节点表单进一步移除接入方式、通道访问主机、客户端接入主机、客户端接入端口和来源限制；数据库升级至 schema v13，节点接入类型字段已从 API、模型、读写 SQL 和 `nodes` 表中彻底删除。
- 修正节点页 Client 统计：改为展示节点 API 返回的真实 Client 数量，首次加载和“检查连接”均会刷新，不再用平台项目绑定数冒充节点 Client 数。
- 节点卡片可直接进入真实 Client 列表，展示 ID、名称、连接地址、状态、版本和流量；既有 Client 不提供编辑、启停或删除。
- 系统管理员可从列表新增 Client；公开 API 不提供 Client 修改或删除路由。
- Client 弹窗放大至 1120px，列表增加默认遮挡的唯一验证密钥；点击 Client 可查看默认隐藏的 Basic 用户名、Basic 密码和唯一验证密钥。
- 新增 Client 支持由管理员设置 Basic 用户名、Basic 密码和唯一验证密钥；后端拒绝重复密钥。单 Client 凭据端点限系统管理员、禁止缓存并记录查看审计。
- 新增表单重做视觉层级、留白、输入聚焦、表格密度和响应式布局，并为 Basic 用户名、Basic 密码和唯一验密钥增加上下文帮助。
- Basic 用户名保持必填；Basic 密码和唯一验证密钥可留空，后端生成 16 位 `0-9a-z` 凭据，与节点默认格式一致并使用更强的操作系统加密随机源。
- Go 全量测试、前端类型检查、Lint、生产构建和 18 项前端契约测试通过；测试环境真实读取 20 个 Client，且无编辑/删除控件。

## 2026-08-02 Web 与 WebSSH 专项修复

### 问题与修复

- 定位 AdGuard Home 偶发无法加载：路径兼容代理错误改写压缩 JavaScript 的正则字面量，产生 `Invalid regular expression flags`。
- 根路径重写收窄为可判定 URL 的 HTML、CSS、JavaScript 和 JSON 字符串，保留正则、普通斜杠和协议相对 URL。
- 补齐本地开发 wildcard 会话 URL 的端口保留。
- WebSSH 增加方向键、Home/End、Delete、PageUp/PageDown、Ctrl/Alt 组合键、粘贴和可聚焦终端语义。
- WebSSH 撤销改为 WebSocket 1008 正常关闭并返回中文原因，错误不再被笼统“已断开”覆盖。
- 安全审查发现 wildcard 内部路由标记曾使用可伪造请求头；已改为服务端请求上下文，防止关闭路径和 Cookie 隔离。

### 真实验证

- `10.10.0.1:3000`、`10.10.10.2:3000` 的 AdGuard Home 登录页和首屏 JS/CSS/PNG/SVG 全部经平台返回 200。
- 会话内 `/control/status` 正确透传未登录 401，不逃逸到控制面。
- 浏览器完整渲染 AdGuard Home 中文登录页；LuCI 跳转至会话内 `/cgi-bin/luci/` 并显示授权页。
- 专用 SSH 设备通过外部凭据和固定主机指纹进入真实 OpenWrt BusyBox 终端。
- 错误密码返回 `ssh_handshake_failed` 和观测指纹；撤销后 WebSocket 1008、中文原因、旧链接 410。
- 伪造内部子域标记时，重定向仍限制在短期会话路径，设备 Cookie 未落到平台根路径。
- 修复后重新通过完整质量门、本地黑盒和 Docker 验收，镜像扫描为 0 漏洞。
