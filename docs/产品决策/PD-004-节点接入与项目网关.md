# PD-004 节点接入与项目网关

- 状态：已接受
- 日期：2026-08-02

## 决策

- 节点常规配置只要求管理 API、TLS 校验主机名、端口池与管理账号/密码；通道主机从 API 地址推导，Client 接入端口由后端统一管理。
- 节点按 API 地址直接接入，不保存或推断“内网、公网、专线、VPN”等网络类型。
- 创建项目只填写项目名称、负责人、接入节点和 Client ID；Client 可从节点实时列表选择，也可手动输入 ID。
- 项目只绑定节点中已经存在的 Client，创建或删除项目都不会创建、修改或删除节点 Client。
- 节点卡片可进入 Client 详情：既有 Client 只读，不提供修改、启停或删除；系统管理员可新增 Client。Basic 用户名必填，Basic 密码和唯一验证密钥可手动设置或留空自动生成。
- 自动凭据使用与节点默认密钥一致的 16 位 `0-9a-z` 格式，随机源使用操作系统加密随机数。
- Client 列表不批量返回认证明文；系统管理员按单个 Client 查看时才从节点读取，界面默认隐藏，响应禁止缓存并记录审计。
- 当前节点实现的 Client ID 与托管 SOCKS ID 相同；项目使用这一数字 ID 直接关联，托管 SOCKS 不是普通端口转发任务。
- 项目创建后单独配置设备发现 CIDR；未配置前只禁止发现扫描，不影响手工登记设备的 Web、WebSSH 或原生服务访问。
- 平台在建立 Web/WebSSH 会话或执行设备发现前自动启动通道，也允许管理员手动启停；30 分钟空闲转为非活跃由节点自身负责，平台不计时、不执行自动停止。

## 凭据

节点管理凭据使用 AES-256-GCM 加密后存入 SQLite，解密主密钥位于数据库外的受控文件中。前端和 API 不回显密码；备份恢复时必须同时保留 SQLite 快照与对应主密钥。

## 删除语义

- 删除项目只删除平台数据，节点中的既有 Client 和 SOCKS 代理始终保留。
- 端口转发、活动会话或运行中扫描存在时拒绝删除项目或设备。Endpoint 不提供独立 CRUD，统一随设备配置原子保存。
