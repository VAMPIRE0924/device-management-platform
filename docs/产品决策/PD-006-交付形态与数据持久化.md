# PD-006 交付形态与数据持久化

- 状态：已接受
- 日期：2026-08-02

## 交付形态

- React/TypeScript 构建为静态 SPA，由 Go `embed` 打入单一 `i5cloud` 二进制。
- 生产容器不包含 Node.js，以 uid/gid 10001 非 root 运行，移除 Linux capabilities 并启用 `no-new-privileges`。
- 同一二进制提供 API、前端、Web 网关、WebSSH、发现、生命周期、健康检查、恢复和 MFA 重置命令。

## 数据持久化

- V1 使用 SQLite 单实例写入，当前 schema 为 v21。
- 数据库启用 WAL、外键、busy timeout 和版本化迁移。
- 设备批量导入、设备与 Endpoint 替换采用事务，不能留下部分写入。
- 在线备份必须通过平台一致性快照接口；禁止复制运行中的数据库文件代替备份。
- 离线恢复先校验完整性和 schema，在替换前保存原数据库快照。

## 备份边界

SQLite 备份包含节点凭据和 SSH 密码密文，但不包含解密主密钥、MFA 主密钥、网页覆盖配置、SMTP 密码、TLS 私钥、API/初始化令牌和 SSH 私钥文件。部署系统必须把这些受限文件与数据库快照成组加密备份。
