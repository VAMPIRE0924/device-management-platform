# PD-001 产品范围与网络边界

- 状态：已接受
- 日期：2026-08-02
- 取代：原《产品需求》《项目方案与可行性评估》中的重复范围说明

## 决策

I5CLOUD 面向多客户内网远程运维。系统管理员接入一个或多个节点，创建客户项目并为项目绑定一个 Client；项目内管理设备发现网段、已登记设备、多个服务入口、发现任务和原生端口转发。

角色边界：

- 系统管理员：管理全部节点、项目、用户、策略、审计、安全设置和数据备份。
- 项目管理员：管理获授权项目中的设备、发现、项目配置和原生服务。
- 运维用户：读取获授权项目并建立允许的远程访问会话。
- 临时用户：只能使用有效访问策略明确授予的项目和 Web/WebSSH 能力。

## 扫描与访问边界

- 项目扫描网段由管理员显式配置为一个或多个 IPv4 CIDR。
- 发现任务的扫描范围必须是项目保存 CIDR 的子集；手工添加、CSV 导入和已登记设备访问不受扫描 CIDR 限制。
- Client 运行在 Docker 时，容器地址只描述运行位置，不能代替或推断客户业务网段。
- 每个节点只配置 API 地址、TLS 校验主机名、认证凭据和端口池；平台不要求用户声明网络接入类型。
- 普通用户和浏览器不获得节点管理凭据、SOCKS 地址或认证信息。

## 明确不做

- 不把设备 Web 服务转换为对公网开放的端口转发。
- 不扫描项目未保存的网段，也不因为 SOCKS CONNECT 成功就判定服务已发现。
- 不把不同项目、Client 或节点的运行状态合并为全局共享状态。
- V1 不支持多实例同时写入同一个 SQLite 数据库。

## 变更条件

改变 Web 网络路径、引入跨项目共享网关、支持主机名目标、支持 IPv6 或多实例写入时，必须新增替代决策并补齐安全与迁移验收。
