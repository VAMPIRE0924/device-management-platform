# PD-003 Web 与 WebSSH 访问架构

- 状态：已接受
- 日期：2026-08-02

## Web

设备 Web 访问链路固定为：

`浏览器 → 五分钟短期会话 → 平台 Web 网关 → 项目托管 SOCKS → 设备 HTTP(S) Endpoint`

- Web 访问不创建、不复用端口转发。
- 每次访问使用不可预测令牌，数据库只保存令牌哈希、来源、状态和到期时间。
- 平台剥离控制面 Cookie、授权头和伪造转发头，再把请求交给设备。
- 路径模式重写同源根路径、重定向和 Cookie，仅作为开发和兼容模式。
- 生产优先使用 wildcard 会话子域名，让每个会话拥有独立站点根路径，兼容绝对路径、动态 API、Cookie 和 WebSocket。
- HTTPS Endpoint 独立保存 TLS 校验主机名。客户内网管理面常用自签证书，因此设备 HTTPS 代理统一允许自签，界面不再暴露重复开关；这不改变平台自身 TLS 和节点 API 的严格校验。

## WebSSH

WebSSH 链路固定为：

`浏览器 WebSocket → 平台 WebSSH 网关 → 项目托管 SOCKS → 设备 SSH Endpoint`

- SSH 目标端口可配置，不限定为 22。
- 管理员可为 SSH Endpoint 选择密码登录或私钥文件登录。密码使用 AES-256-GCM 加密且不回显，私钥只填服务器本地文件路径。
- 未配置长期凭据时，WebSSH 只请求本次连接的用户名和密码，发送后从页面内存清除，不支持上传临时私钥。
- SSH 主机密钥指纹为可选固定值；配置后发生变化必须拒绝连接，未配置时不再设置额外的“允许未知主机密钥”开关。
- 终端支持文本、粘贴、方向键、控制键和窗口大小调整。
- 管理员撤销会话时必须立即关闭 WebSocket 和 SSH 连接；撤销或过期链接返回 410。
- 密码、私钥、SOCKS 凭据和终端内容不写入审计日志。

## 原生服务

SSH 之外需要原生客户端的 RDP、RTSP、数据库和通用 TCP 服务可创建端口转发，必须受端口池、有效期、权限、审计和回收控制。Web Endpoint 永远不能选择该路径。
