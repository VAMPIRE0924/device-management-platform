# PD-002 领域模型与信息架构

- 状态：已接受，V1 前端冻结
- 日期：2026-08-02

## 对象层级

`节点 → 项目 → Client/托管通道 → 设备 → 多个 Endpoint`

- 节点是外部连接能力和端口资源的边界。
- 项目是客户、权限、发现网段和网关的边界，一个项目绑定一个节点和一个 Client。
- 设备在项目内以固定 IPv4 唯一标识。
- Endpoint 是具名服务，可为 HTTP、HTTPS、SSH、RTSP、RDP、MySQL、PostgreSQL 或通用 TCP。
- 同一设备可以有多个同协议、不同端口或不同名称的服务。

## 主菜单

V1 主菜单固定为：概览、访问门户、客户项目、托管通道、接入节点、用户与权限、访问策略、运行监控、访问审计、系统设置。

“内网设备、设备发现、端口转发”属于客户项目详情页的内部标签，不进入主菜单，也不增加左侧子菜单。

## 关键交互

- 页面刷新保持当前 `view` 和项目编号。
- Web 与 WebSSH 在单独浏览器标签页打开；同一次点击只能创建一个访问页面。
- 设备列表把远程访问和配置操作分列，管理按钮不与 Web/WebSSH 挤在同一列。
- 项目、设备、服务、用户、策略和通道列表支持与规模匹配的搜索、筛选和分页。
- 顶部品牌栏与左侧导航固定在可视区域，只有右侧主内容区独立滚动。
- 容易误解的安全字段使用上下文帮助提示；枚举字段使用选择控件，不要求用户记忆内部值。
- 删除和其他破坏性动作必须二次确认，并显示后端依赖冲突。

## 冻结规则

修复按钮行为、权限可见性、错误提示、真实状态来源、响应式布局和后端新增安全字段不视为解冻。新增主菜单、改变对象层级、合并 Web 与管理操作或改变访问路径，必须新增产品决策并重新执行前端验收。
