# DOC-003 任务交接模板

暂停任务、归档对话或交给新开发者时，在当月开发日志追加以下内容。不要新建临时“交接最终版”文件。

```markdown
## YYYY-MM-DD HH:mm 任务交接

### 目标
- 用户要达到的可验证结果

### 已完成
- 修改内容及对应 PD/AC ID

### 验证证据
- 执行的命令、真实协议结果、恢复后的外部状态

### 当前运行状态
- 服务地址、是否为临时数据、是否需要继续保留

### 未完成/受阻
- 事项、原因、解除条件、需要谁提供什么

### 关键文件
- 仓库相对路径，不包含 Secret 内容

### 下一步
1. 可直接继续的第一项工作
2. 需要重新执行的验证
```

## 最小交接要求

- 明确当前数据库是否临时、测试或生产。
- 明确真实节点、通道、转发和会话最终状态。
- 明确哪些凭据文件只可引用，禁止输出内容。
- 明确最后一次通过的自动化门禁及日期。
- 明确用户仍需完成的外部门禁。
- 不把“聊天已归档”当成凭据已经轮换或外部状态已经恢复。
